nerf-bench

Concept A: Instrument

A measuring instrument, not a publication. Neutral greys, one blue for the uncertainty band, one burnt orange reserved for the launch-week baseline. Numbers are set in monospace because they are measurements.

Name and logo

Keeps the working name nerf-bench. The mark is a trace line inside a square frame, with a dashed baseline beneath it: the whole method in one glyph (a line compared against where it started). Drawn at one stroke weight so it holds at 16 pixels.

Rationale

Trust comes from looking like a calibrated tool. The palette is almost colourless so the two colours that do appear always mean the same thing: blue is uncertainty, orange is the launch-week reference. The playful name carries all the personality; everything else stays quiet so a reader never wonders whether the design is editorialising.
